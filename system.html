System-level simulation

Many links, no bits: a PHY abstraction turns the SINR into packets that arrive intact or are lost.

System-level simulation in the sense of Sionna SYS: what matters is how many links work and how well, not the bits of each transmission. A PHY abstraction replaces the bits. It maps a transmission’s SNR to a packet error rate, and the packet is lost with that probability. It is fast, so it suits training and large numbers of agents. LinkLevelChannel (see link) simulates the bits instead, and gives the same packet error rates (tested there).

A system-level channel is a RadioChannel (see radio) whose receiver is a PHY abstraction (an ErrorModel, see phy_abstraction), then Decide, which draws what arrives. The other steps are blocks of their own modules, the same at both levels: h from a Fading (propagation), the power from a PowerControl (power_control), the interference and the SINR (interference), the airtime (radio). The rate of a transmission is link_adaptation’s. Which links transmit when is decided by the Protocol.

System-level channel

A transmission’s SINR gives its packet error rate (the ErrorModel), and the packet is lost with that probability. A packet that arrives is the payload as sent.

  • Size and timing: message.size_bits is the packet size. The timing counts the symbols the error model reports: one per bit for the simple models, the resource elements for SionnaErrorModel.
  • Blocks: the receiver is the ErrorModel, then Decide, which draws whether each packet arrives. transmit_batch handles several transmissions with one call of each block. The backends use it for a step’s transmissions.
  • Subcarriers: with a frequency-selective fading (e.g. RayTracedPathsFading with subcarriers), the error model gets the SINR at each subcarrier.

SystemLevelChannel

class SystemLevelChannel(
    fading:Fading | None=None, # The coefficient h of a transmission; None: h = 1
    power_control:PowerControl | None=None, # Transmit power and outages; None: the link's tx_power_w
    noise_power:float=1.0, # Noise power at the receiver
    per_model:str | ErrorModel='bpsk', # 'bpsk', 'threshold', or an `ErrorModel` (e.g. `SionnaErrorModel`)
    snr_threshold_db:float=10.0, # The 'threshold' model's SNR
    seed:int | None=None, # Seed of the packet losses and the fading
):

A PHY abstraction: SINR -> packet error rate -> the packet arrives intact or is lost. No bits are simulated.

Tests

import math

import numpy as np

from comm_core.core import Message, Transmission
from comm_core.phy_abstraction import EESMErrorModel, packet_error_rate
from comm_core.power_control import ChannelInversion, FixedPower
from comm_core.propagation import NoFading, RayleighFading
from comm_core.topology import Link
def send(ch, link=Link('a', 'b'), n=1, size_bits=100, **metadata):
    t = Transmission(message=Message('a', 'b', 'hi', size_bits=size_bits, metadata=metadata), sender='a', receiver='b', start_time=0.0)
    return [ch.transmit(t, link) for _ in range(n)]

for snr_db, delivered in ((10, 1.0), (0, 0.0)):                 # 100 bits: always through at 10 dB, never at 0 dB
    rs = send(SystemLevelChannel(noise_power=10 ** (-snr_db / 10), seed=0), n=50)
    assert np.mean([r.success for r in rs]) == delivered and abs(rs[0].snr_db - snr_db) < 1e-9
r = rs[0]
assert r.size_bits == 100 and r.energy == 100 and r.latency == 0 and r.metadata == {'channel_gain_db': 0.0, 'tx_power': 1.0}
# in between: lost as often as the packet error rate says, reproducibly
ch = SystemLevelChannel(noise_power=10 ** -0.6, seed=0)        # 6 dB, 100 bits
ch.reset(seed=3); first = [r.success for r in send(ch, n=2000)]
ch.reset(seed=3); assert [r.success for r in send(ch, n=2000)] == first
assert abs(1 - np.mean(first) - packet_error_rate(6, 100)) < 0.03
# the threshold model, channel inversion (outages), a perfect link, a finite bandwidth
assert send(SystemLevelChannel(noise_power=1.0, per_model='threshold', snr_threshold_db=-1))[0].success
for h, sent in ((1.2, True), (0.1, False)):
    r, = send(SystemLevelChannel(fading=NoFading(h), power_control=ChannelInversion(10, max_power=10)))
    assert r.success == sent and r.size_bits == (100 if sent else 0) and r.metadata.get('outage', False) != sent
r, = send(SystemLevelChannel(fading=NoFading(math.inf), noise_power=1e9))
assert r.success and r.snr_db == math.inf
r, = send(SystemLevelChannel(), link=Link('a', 'b', bandwidth_hz=1e6, tx_power_w=0.5))
assert abs(r.latency - 1e-4) < 1e-15 and abs(r.energy - 0.5e-4) < 1e-15
# a frequency-selective fading: the error model gets the SINR at each subcarrier
class TwoSubcarriers(Fading):
    def coefficient(self, transmission, link):
        return 1.0
    def response(self, transmission, link):
        return np.array([1.0, 0.1])                                      # the second subcarrier faded by 20 dB

class Recorder(ErrorModel):
    def rate(self, sinr, size_bits, group=None):
        self.sinr = sinr
        return np.zeros(len(sinr)), np.asarray(size_bits), [{'seen': True} for _ in sinr]

recorder = Recorder()
r, = send(SystemLevelChannel(fading=TwoSubcarriers(), noise_power=0.1, per_model=recorder))
assert np.allclose(recorder.sinr[0], [10.0, 0.1]) and r.metadata['seen']
assert abs(r.snr_db - 10 * np.log10(np.mean([10.0, 0.1]))) < 1e-9          # the mean SNR
# a batch: the same results as one at a time, with one call of the error model
ch1, ch2 = SystemLevelChannel(noise_power=10 ** -0.6, seed=4), SystemLevelChannel(noise_power=10 ** -0.6, seed=4)
pairs = [(Transmission(message=Message('a', 'b', k, size_bits=100), sender='a', receiver='b', start_time=0.0), Link('a', 'b')) for k in range(50)]
assert [r.success for r in ch1.transmit_batch(pairs)] == [ch2.transmit(t, l).success for t, l in pairs]
try:
    SystemLevelChannel(per_model='qam'); raise AssertionError('no error')
except ValueError:
    pass

In a Network, the topology and the protocol decide which transmissions happen, and the channel decides what arrives:

from comm_core import Network, Node, FullMeshTopology, IdealProtocol, AnalyticalBackend
from comm_core.propagation import RayleighFading
ch = SystemLevelChannel(fading=RayleighFading(), power_control=ChannelInversion(10, max_power=20), seed=0)
nodes = ['a', 'b', 'c']
net = Network([Node(n) for n in nodes], FullMeshTopology(nodes), IdealProtocol(), AnalyticalBackend(ch))
net.reset(seed=0)
for step in range(20):
    for s in nodes:
        for r in nodes:
            if s != r:
                net.send(Message(s, r, payload=step, size_bits=64))
    net.step()
m = net.metrics.summary()
assert m.transmissions == 20 * 6 and 0 < m.failed < m.transmissions        # deep fades: outages
# a broadcast: the error model gets its copies' broadcast (`group`)
class Grouped(ErrorModel):
    def rate(self, sinr, size_bits, group=None):
        self.group = group
        return np.zeros(len(sinr)), np.asarray(size_bits, int), [{} for _ in sinr]
nodes = ['a', 'b', 'c']
for model in (Grouped(), 'bpsk', 'threshold', EESMErrorModel(beta=1.0, threshold_db=0.0)):
    ch = SystemLevelChannel(per_model=model, noise_power=1e-3)
    net = Network([Node(n) for n in nodes], FullMeshTopology(nodes), IdealProtocol(), AnalyticalBackend(ch))
    sent = net.broadcast('a', payload=1, size_bits=8)
    net.send(Message('b', 'c', payload=2, size_bits=8))
    assert all(r.success for r in net.step())
groups = Grouped()
net = Network([Node(n) for n in nodes], FullMeshTopology(nodes), IdealProtocol(), AnalyticalBackend(SystemLevelChannel(per_model=groups)))
sent = net.broadcast('a', payload=1, size_bits=8)
net.send(Message('b', 'c', payload=2, size_bits=8))
net.step()
assert groups.group == [sent[0].metadata['broadcast']] * 2 + [None]
# no broadcast in the step: no `group`
net.send(Message('b', 'c', payload=2, size_bits=8)); groups.group = 'unset'; net.step()
assert groups.group is None

Its blocks

The channel is its blocks: pipeline() gives them, and a PipelineBackend (see backend) runs a pipeline of your own. Here a block of shadowing is added after the fading:

from comm_core.backend import PipelineBackend
from comm_core.block import Block
from comm_core.interference import SINR
from comm_core.radio import Airtime
ch = SystemLevelChannel(fading=RayleighFading(), noise_power=0.1, seed=0)
assert [type(b).__name__ for b in ch.pipeline()] == ['RayleighFading', 'FixedPower', 'SINR', 'BPSKErrorModel', 'Decide', 'Airtime']
assert ch.pipeline() is ch.pipeline()                                    # built once, while the blocks stay
ch.fading = NoFading(1.0)
assert type(ch.pipeline()[0]).__name__ == 'NoFading'                       # an attribute changed: a new pipeline

class Shadowing(Block):
    "A loss of `db` on every link."
    outputs = ('h',)
    def __init__(self, db):
        self.db = db
    def call(self, h):
        return h * 10 ** (-self.db / 20)

backend = PipelineBackend([NoFading(1.0), Shadowing(10.0), FixedPower(), SINR(), BPSKErrorModel(), Decide(), Airtime()],
                          noise_power=0.01)
t = Transmission(message=Message('a', 'b', 'hi', size_bits=100), sender='a', receiver='b', start_time=0.0)
r = backend.transmit(t, Link('a', 'b'))
assert abs(r.snr_db - 10) < 1e-9 and abs(r.metadata['channel_gain_db'] + 10) < 1e-9 and r.success   # 20 dB - 10 dB
# the same results as the channel, block for block
ch = SystemLevelChannel(noise_power=10 ** -0.6, seed=4)
same = PipelineBackend(ch.pipeline(), noise_power=ch.noise_power)
ch.reset(seed=4); a = [r.success for r in ch.transmit_batch([(t, Link('a', 'b'))] * 200)]
ch.reset(seed=4); b = [r.success for r in same.transmit_all([(t, Link('a', 'b'))] * 200)]
assert a == b and 0 < sum(a) < 200
